# Automações com IA

Com automações em IA no Microsoft Copilot Studio pode-se:

- Consultar sistemas internos de rede.
- Consumir APIs dos seus sistemas (Sistemas internos / externos).
- Correlacionar alarmes e eventos.
- Auxiliar troubleshooting.
- Identificar possíveis causas de falhas.
- Consultar documentação técnica e procedimentos.
- Executar automações controladas.

## Objetivo

Capacitar a equipe a desenvolver agentes inteligentes utilizando Microsoft Copilot Studio integrados a sistemas corporativos, APIs e bases de conhecimento para suporte operacional, troubleshooting, observabilidade e automação de processos de rede.
